# Palette's Journal

## 2024-05-22 - Standardization of Visual Signals
**Learning:** Users rely on consistent visual markers (like emojis) to quickly scan lists. Hardcoding a single icon (🧭) for variable states (Modality) breaks this scanning pattern and contradicts the established visual language of the platform.
**Action:** When displaying stateful data, ensure the visual icon maps dynamically to the state, rather than using a generic placeholder.
